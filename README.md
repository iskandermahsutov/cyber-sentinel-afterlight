# CYBER SENTINEL: AFTERLIGHT 8.1

Браузерная 2D Pixel Art игра: 16 миссий, четыре акта, герои BYTE и NOVA.

**Разработчик:** Махсутов Искандер Жасурулы  
**Академическая группа:** ИС-44

## Запуск
Откройте index.html в Chrome. Установка и сборка не требуются. Для жестов нужны интернет и разрешение камеры. Для веб-публикации используйте HTTPS.

## Клавиатура
| Клавиша | Действие |
| --- | --- |
| A/D или ←/→ | Движение |
| W/↑/пробел | Прыжок |
| J/F | Стрельба |
| K | Ближняя атака |
| Shift | Рывок BYTE / щит NOVA |
| Tab | Смена героя |
| Q | Способность |
| E | Взаимодействие |
| G | Режим напарника |
| 1/2/3 | Протокол / ответ |
| I | Информация |
| O | Цели |
| P/Esc | Пауза |
| Enter | Начать / продолжить из меню |

Терминалы: WASD/стрелки, пробел/Enter — выбор, H — подсказка. Клавиши независимы от раскладки.

## Жесты
Нажмите «AI ЖЕСТЫ · ВКЛЮЧИТЬ», разрешите камеру, дождитесь модели и начните миссию.

| Жест | Действие |
| --- | --- |
| Открытая ладонь слева/справа в зеркальном превью | Движение |
| Кулак | Огонь при удержании |
| Указательный вверх | Прыжок |
| V | Смена героя |
| Большой палец вверх | Взаимодействие (E) |
| I Love You: большой, указательный, мизинец | Способность (Q) |

Порог уверенности 0,65. Разовые действия требуют двух распознаваний и имеют задержку 1,25 с. Две руки могут сочетать движение и огонь. Терминалы проходятся клавиатурой/мышью. «ВЫКЛЮЧИТЬ КАМЕРУ» освобождает камеру. Клавиатура доступна и при отказе в разрешении.

## AI и технологии
- Google MediaPipe Tasks Vision GestureRecognizer: ML-распознавание жестов, WebAssembly, локальная обработка.
- Взвешенный k-NN: классификация киберугроз и выбор контрмер.
- Адаптивный директор атак: изменение интенсивности по состоянию игры.
- HTML, CSS, JavaScript, Canvas 2D, локальное сохранение.

MediaPipe закреплён на 0.10.22-rc.20250304. JS/Wasm загружаются с jsDelivr, модель gesture_recognizer.task — с Google Storage. Игра не записывает и не отправляет кадры камеры; внешние серверы получают запросы загрузки зависимостей. Сторонние компоненты сохраняют свои лицензии.

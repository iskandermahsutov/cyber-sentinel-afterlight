# Размещение HTML5-версии

## GitHub Pages

Файл `index.html` расположен в корне проекта. Публикация выполняется из ветки `main`, каталог `/(root)`.

[Открыть игру](https://iskandermahsutov.github.io/cyber-sentinel-afterlight/)

## itch.io

Архив для загрузки должен содержать `index.html` в корне.

Настройки проекта:
- Тип: HTML.
- Категория: Games.
- Оплата: No payments.
- Файл: This file will be played in the browser.
- Запуск: Click to play или Click to launch in fullscreen.

Для управления жестами требуются интернет и разрешение камеры. Встраивание через iframe может ограничивать доступ к камере; полноэкранный режим не меняет эти разрешения. В таком случае игру можно открыть на GitHub Pages.

После загрузки необходимо проверить запуск, клавиатуру, сохранение прогресса и распознавание жестов на реальной камере.

[Документация itch.io](https://itch.io/docs/creators/html5)
